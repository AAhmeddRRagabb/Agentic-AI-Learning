# Agentic-AI
This repository is intended to document and support my learning journey toward mastering **Agentic AI**, inshallah.

The roadmap for this journey can be accessed using this [link](https://drive.google.com/file/d/1WFqjW08etEd_TPsuy02QxBnbT7WDcfzF/view?usp=sharing). It is divided into structured phases, where each phase focuses on specific concepts, topics, and practical tasks. The roadmap was primarily developed by [Eng. Ahmed hossam](https://github.com/Eng-Ahmed-Hossam).



## Repository Structure
The repository will be organized as follows:

* `learning/`: The main learning directory . Each phase will have its own independent subdirectory inside the `learning/` directory. Each learning topic will be placed in a separate folder within its corresponding phase, containing its related concepts, notes, and practice tasks.
* `projects`: This folder will contain links to projects done through the learning journey & the concepts they are applied to.



## Requirements to Run the Python Code inside Learning Phases

1.0 Python 3.13 or later.

2.0 Create and activate a virtual environment recommended.

* Windows
```bash
python -m venv venv_name
venv_name\Scripts\activate
```

* PowerShell
```bash
python -m venv venv_name
.\venv_name\Scripts\Activate.ps1
```

* Linux/macOS
```bash
python3 -m venv venv_name
source venv_name/bin/activate
```

3.0 Install the required dependencies.

```bash
pip install -r requirements.txt
```

4.0 Copy the `.env.example` file into a `.env` file, then put the important values in the `.env`
```bash
cp .env.example .env
```
